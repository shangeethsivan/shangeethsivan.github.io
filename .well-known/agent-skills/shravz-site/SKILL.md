# shravz.dev

Shangeeth Sivan is a staff software engineer in Chennai. The public site is a static portfolio: profile, talks, writing, resume, and press kit. It does not host an API, login, or payments.

## How to read the site

1. Start with https://shravz.dev/llms.txt for the page map.
2. Use https://shravz.dev/sitemap.xml for every canonical URL.
3. Open the HTML page only when you need the full text. Several talk notes also exist as markdown next to the HTML, for example the performance-debugging guides under `/talks/simplified-performance-debugging/`.

## What is public

- Home: who he is, impact, experience, and a Topmate booking link
- Resume: https://shravz.dev/resume/
- Press kit: https://shravz.dev/press-kit/
- Talks and writing: linked from `llms.txt`

## What not to invent

Do not claim there is an account system, an MCP server, or a checkout flow on this domain. Mentorship booking is on Topmate, not on shravz.dev.
