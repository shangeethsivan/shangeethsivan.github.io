09 · The build

Debuggable builds lie.

DebugFor bugs. JIT is off. AOT is unwound. You measured the debugger.
ProfileableAndroid 10 and newer. Release speed. The tools can attach.

Keep the file and the line. Retrace the names. -keepattributes SourceFile,LineNumberTable

AndroidManifest.xml

<application>
  <profileable
      android:shell="true"
      android:enabled="true" />
</application>

shell lets Perfetto and Simpleperf attach. A benchmark variant copies release, signs with debug, and stays non-debuggable.

10:40 – 12:00

Hard cut. Read the headline, then profileable, then the manifest. shell true is the part that matters. enabled defaults to true from API 30. The variant, if asked: initWith release, debug signing, matchingFallbacks release, isDebuggable false, isProfileable true. keepattributes keeps file and line. Method names can still be obfuscated. Retrace with the mapping file. There is no bar chart of “how much slower.” We do not have that number.
