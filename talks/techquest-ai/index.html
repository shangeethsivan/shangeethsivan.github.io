📄 1951 BELL LABS RESEARCH PAPER

Theoretical Human Experiment

Before software apps or AI existed, Claude Shannon ran a pen-and-paper statistical experiment at Bell Labs, asking human subjects (including his wife Betty) to guess the next letter in covered sentences.

Proved Language is Statistical

Shannon mathematically proved that given context like "THINK FAST. BUILD FASTER. SHIP TODA...", the next character is statistically predictable. This theoretical paper founded the principle modern LLMs use today.

AI MECHANICS · INPUT & OUTPUT TOKENS

How an LLM Actually Works

From prompt tokens to streaming response tokens in 4 clear steps.

01

1. Input Tokens

Your prompt & context are sliced into input tokens (~4 characters each).

02

2. Context Window

The total token capacity (Input + Output tokens) the model can hold in memory at once.

03

3. Predict Next

Scores 100k+ candidate words and picks the single best next token.

04

4. Output Tokens

Appends the token, streams it to the UI, and repeats until finished.

INPUT TOKENS (PROMPT)

Everything you send in (question, documents, instructions). Processed in parallel and usually cheaper.

OUTPUT TOKENS (COMPLETION)

Generated token-by-token in real time. Total tokens = Input + Output (must fit inside the Context Window).

KEY VOCABULARY

The Terms You'll Hear Today

Six fundamental concepts you will use throughout the workshop.

Model

The trained AI you call (e.g. GPT-4o, Claude, Llama). Different models = different skill, speed, cost.

Token

A word-piece. Prompts and replies are measured — and billed — in tokens.

Context window

The max tokens a model can hold at once. Prompt + reply must fit inside it.

Temperature

Creativity dial. Low = focused and repeatable, high = varied and surprising.

Hallucination

When a model states something wrong with full confidence. Always sanity-check facts.

System prompt

Hidden instructions that set the model's role and rules before the user types anything.
