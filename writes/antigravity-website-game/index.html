How to build a website/game using Antigravity

Download the desktop app, open a project, and paste a prompt. Need more quota first? See Jio setup help.

Illustrated — not an official screenshot.
Step 1

Open the download page

Go to antigravity.google/download.

Illustrated — not an official screenshot.
Step 2

Download Antigravity 2.0

Pick your system: Mac, Windows, or Linux.

Illustrated — not an official screenshot.
Step 3

Run the installer

Open the file you downloaded. If it asks Keep Both or Replace, pick Replace.

Illustrated — not an official screenshot.
Step 4

Launch and sign in

Open Antigravity. Sign in with your Google account. See getting started if the app looks different.

Illustrated — not an official screenshot.
Step 5

New Project → paste a prompt

Click New Project, add a folder on your computer, then paste one of the prompts below into chat.

Sample prompts

Pick Simple or Complex, copy one, paste it into Antigravity.

Website 
Build a single-page mobile-first website I can open as one HTML file. White background, huge readable type, Outfit font. Hero with a name and one-line bio. Three project cards. Footer with Instagram and YouTube. No backend, no build step.
Game 
Build a simple browser game I can open as one HTML file. Catch falling items: I move left and right, items drop from the top, score goes up when I catch them. Big on-screen buttons for a phone. No backend, no build step.

Unofficial guide. Google can change Antigravity screens — prefer the live download and docs if they disagree.

You need a network connection to download Antigravity or open Google sign-in.
